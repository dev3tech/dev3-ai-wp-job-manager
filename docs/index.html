1. Installation

  1. Install and activate WP Job Manager from Plugins → Add New (it is free).
  2. Upload dev3-ai-wp-job-manager.zip in Plugins → Add New → Upload Plugin and activate it.
  3. In Job Listings → Settings → Job Submission/Listings, turn on Enable Job Salary, salary currency and salary unit so normalised salaries have a place to go. Turn on Remote Position if you post remote jobs.
  4. Open DEV3 AI Jobs in the admin menu. Every listing gets a quality score the first time you open the Listings screen.

No licence key or activation. Everything except AI writing and AI explanations works right away without an API key.

2. Google Gemini API key

  1. Go to Google AI Studio → API keys and create a key.
  2. In DEV3 AI Jobs → API Config, paste the key and press Save, then Test connection.
  3. Pick models (defaults: gemini-2.5-flash for everything, gemini-2.5-pro available).
  4. Set a monthly budget (USD). When it is reached, AI pauses and the plugin keeps working with rules and templates.

Alternatively define the key in wp-config.php: define( 'DEV3JM_GEMINI_API_KEY', '…' );. The key is stored encrypted (AES-256-GCM), only used server-side and never sent to the browser.

Switches in API Config: AI on/off (all features), visitor AI on/off (only the submit-form assistant), response cache, PII masking.

3. Dashboard & quality score

The dashboard shows how many listings you have, their average quality, how many need attention, how many have an unclear salary or exclusionary wording, and how many drafts are waiting in the review queue. The setup card checks WP Job Manager's version, salary fields, job tags and Resume Manager.

4. Listing editor

Open a listing from DEV3 AI Jobs → Listings. On the left is the quality checklist; on the right are the tools:

  • Description: add optional notes, pick a tone and press Write with DEV3 AI. The draft appears next to the current text (Changes / Side by side / Draft). Edit it if you like, then Save to listing. Without AI you get a clean outline built from the current text.
  • Inclusive language: Check with DEV3 AI (word list + AI) or Word list only. Untick fixes you do not want and press Apply fixes.
  • Salary & title: Normalise (rules) or Ask DEV3 AI. Check the fields and save; they go into WP Job Manager's own salary, currency and unit fields.
  • Types & tags: suggestions from your existing job types and categories plus skill tags. Tick what you want and save.
  • Schema: the JobPosting JSON-LD WP Job Manager prints for this listing and a Google for Jobs checklist.

5. Job edit screen

The DEV3 AI Job Assistant box in the sidebar of the job editor (block or classic editor) shows the saved quality score and offers Write with DEV3 AI, Check wording and Normalise salary & title. Accepted drafts are inserted into the editor and the WP Job Manager fields, so they are saved when you press Update; nothing is written behind the editor's back.

6. Front-end submit form

On pages with [submit_job_form], employers see a Writing assistant under the description:

  • Help me write it: notes + tone → a suggested ad they can use or discard.
  • Check wording: flagged phrases with Replace buttons.
  • Suggest type & tags: selects the job type and adds tags.
  • A live salary reading under the salary field ("Reads as USD 50,000 – 70,000 per year") with a button to set the currency and period.

Visitor-facing text is neutral (no plugin branding). The routes are public (employers may not be logged in) but same-origin only, rate-limited per IP (Settings), cached, and fall back to the template/word list when AI is off, paused or failing. When no Job Tags add-on is active, the form also gets a Tags field.

Examples the rules understand:

INR 12 LPAINR 1,200,000 per year
up to 90000 / from 60kMaximum only / minimum only
CompetitiveFlagged: no amount

A bare "$" uses your WP Job Manager default currency when it is a dollar currency, otherwise USD. When no pay period is given it is guessed from the amount and flagged for review. DEV3 AI is only asked when the rules cannot read the salary (or when you press Ask DEV3 AI).

Titles: hype words (rockstar, ninja, guru…), emojis, "URGENT", "!!!" and pay are removed; abbreviations are expanded (Sr → Senior, JS → JavaScript, Mgr → Manager); ALL CAPS becomes Title Case. Seniority (entry, mid, senior, lead, executive) is stored for the schema.

8. Job types & tags

Job type rules look for phrases such as "part-time", "20 hours per week", "contract", "internship", "fixed-term". Tags come from your existing tags plus ~120 common skills (filter dev3jm_skill_vocabulary). DEV3 AI is constrained to the job types and categories that exist on your site.

If the WPJM Job Tags add-on is active, its job_listing_tag taxonomy is used. Otherwise this plugin registers a taxonomy with the same name (Settings → Job tags taxonomy), so your tags carry over if you install the add-on later, and shows tags on the single job page.

9. JobPosting schema

The plugin hooks wpjm_get_job_listing_structured_data, so there is still exactly one JSON-LD block. Improvements:

  • baseSalary with numeric minValue/maxValue (or value), ISO currency and unitText. An unreadable salary is left out instead of printing invalid text.
  • Remote jobs: jobLocationType: TELECOMMUTE and applicantLocationRequirements (from geolocation, the location's last part or Settings → Remote applicant country), even without a location.
  • employmentType for job types without WPJM's employment type meta, plain-text locations turned into a PostalAddress, experienceRequirements, skills (tags), industry (first category) and a stable identifier.

Turn it off with Settings → Improve JobPosting schema. Filter the result with dev3jm_schema.

10. Candidate matching

Requires the WP Job Manager Resume Manager add-on (paid, from wpjobmanager.com). Choose a job in DEV3 AI Jobs → Matching to rank resumes:

  • Skills (40%): the job's tags (or skills found in the description) present in the resume's skills or experience.
  • Experience (25%): years from the resume's experience dates vs. the job's seniority or "N+ years".
  • Role fit (20%): overlap of the job title with past titles.
  • Location (15%): 100 for remote jobs, otherwise city/country match.

Explain top 10 with DEV3 AI adds a model review; the final score is the average of the rules and the model, so it stays grounded. Results are stored and can be exported or erased with the WordPress privacy tools.

Decision support only. Scores never change a resume or application, and every candidate stays visible.

11. Bulk improve & review

  1. DEV3 AI Jobs → Bulk improve: choose listings (low quality, missing salary, missing type/tags, exclusionary wording, all, or the ones selected in Listings).
  2. Choose improvements: rewrite description, inclusive fixes, normalise salary, clean up titles, suggest types & tags. Toggle DEV3 AI on or off.
  3. Start: the run uses the core background job queue (WP-Cron; on hosts without working cron it advances while the progress bar is open).
  4. Review queue: open each draft to see the changes, edit and accept, or reject. Accept safe changes applies salary, title, seniority, type and tag changes in one go and keeps description rewrites for review.

13. Privacy & fairness

  • Listing text goes to Google Gemini only for AI features and only with your key. Resume data for matching is built from an allow-list (headline, city/region, skills, experience titles/employers/dates/notes, education), free text is masked (emails, phones, card numbers, IPs), the candidate's name is replaced, and self-declared protected attributes ("Gender: …", "Date of birth …") are removed.
  • Never used or sent: name, email, phone, photo, video, links, age/date of birth, gender, marital or family status, nationality, ethnicity, religion, disability, health, sexual orientation, union membership, political views, street address.
  • Privacy policy text is added under Settings → Privacy. Tools → Export/Erase Personal Data include match scores (found through the resume's email or author).
  • Uninstall removes plugin data only when "Delete data on uninstall" is on (API Config).

15. FAQ

Does it change my listings automatically?

No. AI and bulk results are drafts; listings change only when you accept. The only automatic change is the optional, rules-only "Normalise salary on submit".

I don't see the assistant on the submit form.

Check that the page uses [submit_job_form] and that at least one submit-form feature is on in Settings. The salary reading needs WPJM's salary field enabled.

Bulk runs stay at 0%.

Your host's WP-Cron may be off. Keep the Bulk improve screen open: the progress bar advances the run itself after 30 seconds.

Does matching work without Resume Manager?

No, it reads Resume Manager's resumes. Everything else works without it.

Which WP Job Manager versions are supported?

1.36 or later (salary fields). Tested with 2.4.
